## Course Overview

This course introduces the UNIX programming environment and teaches foundational programming concepts in C.
Selected topics: coding conventions and style, variables, arrays and strings, functions, recursion, pointers, dynamic memory allocation and data structures, linked lists, graphs, abstract data types, object-oriented design.
